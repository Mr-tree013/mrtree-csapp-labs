# Data Lab

实现一组位操作函数，仅使用有限的位级运算符。

## 目标

- 理解整数（补码）和浮点数（IEEE 754）的位级表示
- 掌握位运算技巧

## 文件

- `bits.c` — 需要实现的函数
- `bits.h` — 函数声明与约束

## 约束

- 只能使用 `! ~ & ^ | + << >>`
- 禁止使用循环、条件、大于 8-bit 的常量
- 禁止使用 `&& || == !=` 等运算符
- 禁止使用宏、函数调用、类型转换
