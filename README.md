# CS:APP Labs

CMU 15-213 / CS:APP3e 配套实验。

| # | Lab | 主题 | 关键词 |
|---|-----|------|--------|
| 1 | Data Lab | 位操作与整数/浮点数表示 | 位运算、补码、IEEE 754 |
| 2 | Bomb Lab | 逆向工程与汇编级调试 | x86-64、GDB、反汇编 |
| 3 | Attack Lab | 代码注入与 ROP 攻击 | 缓冲区溢出、栈帧、gadget |
| 4 | Cache Lab | 缓存结构与性能优化 | 缓存模拟器、矩阵分块 |
| 5 | Shell Lab | 进程控制与信号 | fork、exec、信号处理 |
| 6 | Malloc Lab | 动态内存分配器 | 隐式/显式空闲链表、碎片 |
| 7 | Proxy Lab | 并发网络编程 | HTTP、I/O 多路复用、并发 |
